# app module

## Описание
Основной модуль приложения TagsGallery, предоставляющий точку входа в приложение.
Содержит DI модуль для глобального графа зависимостей, полноэкранный просмотрщик медиа
с возможностью редактирования его тегов и удаления, а также навигацию между feature-модулями.

## Структура
```
app/
├── src/
│   └── main/
│       ├── java/
│       │   └── com/dgopadakak/tagsgallery/
│       │       ├── App.kt              # Класс приложения (инициализация БД при первом запуске)
│       │       ├── MainActivity.kt     # Основная активность (точка входа)
│       │       ├── di/                 # Dependency Injection
│       │       ├── ui/                 # Корневой UI и полноэкранный просмотрщик
│       │       └── navigation/         # Данные для навигации
│       └── res/                        # Ресурсы приложения
```

## Зависимости
- Hilt для DI
- Jetpack Compose для UI
- Jetpack Compose Navigation для навигации
- Room и DataStore для первоначальной инициализации БД при необходимости
- Zoomable Image (telephoto) для просмотра изображений с динамически прогружаемым масштабированием в полноэкранном просмотрщике
- Media 3 для воспроизведения видео в полноэкранном просмотрщике
- Все остальные модули приложения
