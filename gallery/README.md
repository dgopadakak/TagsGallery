# gallery module

## Описание
Модуль, отвечающий за выбор медиа из файловой системы через PhotoPicker, выбор тегов и последующую
привязку к выбранным медиа выбранных тегов. Доступна гибкая система индивидуального выбора и
индивидуального исключения тегов для отдельных медиа. Список общих тегов имеет функционал фильтрации
и сортировки.

## Структура
```
gallery/
├── src/
│   └── main/
│       └── java/
│           └── com/dgopadakak/tagsgallery/gallery/
│               ├── GalleryViewModel.kt   # ViewModel, содержащая UiState
│               ├── ui/                   # UI компоненты
│               └── util/                 # Вспомогательные утилиты
```

## Основные компоненты
- GalleryViewModel, взаимодействующая с репозиторием из модуля core/local_storage с целью привязки тегов к медиа
- UI компоненты с превью в виде сетки изображений для выбранных к добавлению медиа-файлов и списком тегов

## Функционал
- Добавление медиа через PhotoPicker
- Выбор тегов
- Индивидуальная настройка (добавление, исключение) тегов для отельных медиа
- Привязка выбранных тегов к выбранным медиа с учетом индивидуальных настроек для каждого медиа

## Зависимости
- Jetpack Compose для UI
- Hilt для inject'а зависимостей
- Coil для отображения превью медиа
- Media 3 для анимации выбранных превью видео
- core/local_storage для работы с репозиторием
- core/compose для переиспользования общих UI компонентов
