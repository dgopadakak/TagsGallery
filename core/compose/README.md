# core/compose module

## Описание
Модуль, содержащий общие UI компоненты и модели данных для приложения TagsGallery. Предоставляет
переиспользуемые UI компоненты в основном для работы с тегами, а также общие модели.

## Структура
```
core/compose/
├── src/
│   └── main/
│       └── java/
│           └── com/dgopadakak/tagsgallery/core/compose/
│               ├── ui/                   # UI компоненты
│               ├── models/               # Общие модели данных
│               └── enums/                # Enum для UI
```

## Основные компоненты
- UI компоненты для сортировки, фильтрации и отображения тегов; данные для этих компонентов
- FullscreenContentModel — модель данных для полноэкранного просмотра медиа
- Вспомогательные Composable функции и функции-расширения

## Зависимости
- Jetpack Compose для UI
- core/local_storage для доступа к модели тега
