# core/local_storage module

## Описание
Модуль, отвечающий за локальное хранение данных. Предоставляет централизованное API для работы с
хранимыми данными, такими как настройки, данные о тегах и их связях с медиа. Централизованное API
позволяет не задумываться о способе хранения данных в модулях, использующих данное API.

## Структура
```
core/local_storage/
├── src/
│   └── main/
│       └── java/
│           └── com/dgopadakak/tagsgallery/core/local_storage/
│               ├── Repository.kt         # Основной репозиторий
│               ├── room/                 # Room компоненты
│               ├── preferences/          # SharedPreferences (DataStore)
│               ├── models/               # Модели данных
│               ├── enums/                # Enum для DataStore
│               └── util/                 # Вспомогательные утилиты
```

## Основные компоненты
- Repository - центральный репозиторий, который предоставляет единый API для работы с данными БД и Preferences
- Основные модели для тегов и их связей с медиа, являющиеся сущностями базы данных
- Room компоненты: класс БД, DAO. Служат сохранению данных о тегах и их связях с медиа
- PreferencesRepository - репозиторий для работы с DataStore<Preferences> для сохранения информации о настройках, список которых пока не сформирован до конца

## Зависимости
- Room для работы с базой данных
- DataStore для хранения настроек
