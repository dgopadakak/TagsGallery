# Инструменты для материалов Google Play

Скрипты, которыми собраны иконка, feature graphic и карточки скриншотов в
`google-play-res/`. Всё рисуется кодом на Pillow — правки вносятся в константы,
а не мышью в редакторе.

## Установка

```bash
cd google-play-res/tools
python -m venv venv
./venv/Scripts/python.exe -m pip install -r requirements.txt   # Windows
# source venv/bin/activate && pip install -r requirements.txt  # Linux/macOS
```

Шрифт берётся из `C:\Windows\Fonts\segoeuib.ttf` (Segoe UI Bold) и `segoeui.ttf`.
На другой ОС поправьте `render_feature.font()`.

## Что где

| Файл | Назначение | Куда пишет |
|---|---|---|
| `render_icons.py` | Варианты иконки приложения из геометрии `ic_launcher_*.xml` | `tools/` |
| `render_feature.py` | Общие примитивы: градиент, цвета, форма ярлыка, плитка иконки, шрифт | — |
| `render_feature_wall.py` | Feature graphic 1024×500, обе локали | `../feature_graphic_*.png` |
| `render_cards.py` | Движок карточки: подпись + панель со скриншотом | — |
| `card6.py` | Карточка «адаптивность»: планшет и телефон внахлёст | `../screenshots/*/` |
| `cards_ru.py` / `cards_en.py` | Сборка семи карточек комплекта | `../screenshots/ru|en/` |
| `seed_db.py` | Заполнение базы приложения тегами и связями | устройство |
| `demo.sh` | Чистый статус-бар на эмуляторе (`demo` и `shoot`) | — |
| `raw/` | Исходные скриншоты с устройства | — |

## Как поменять подпись на карточке

```bash
# правите строку в CARDS внутри cards_ru.py
./venv/Scripts/python.exe cards_ru.py
```

Пересоберётся весь комплект из `raw/`. Пересъёмка на устройстве не нужна —
ради этого исходники и лежат рядом.

## Как переснять экраны

Съёмка полуавтоматическая: координаты нажатий смещаются при смене локали и
количества тегов, поэтому каждый шаг проверяется скриншотом.

```bash
. ./demo.sh                  # даёт функции demo и shoot
adb root
python seed_db.py ru
adb shell cmd locale set-app-locales com.dgopadakak.tagsgallery --locales ru-RU
adb shell cmd uimode night yes      # или no
demo                                 # чистый статус-бар: 9:41, Wi-Fi, 100%
adb shell "am force-stop com.dgopadakak.tagsgallery; am start -n com.dgopadakak.tagsgallery/.MainActivity"
# ... переходы через adb shell input tap ...
shoot raw/ru_1_gallery.png
```

Планшетный кадр без отдельного AVD:

```bash
adb shell wm size 2560x1600 && adb shell wm density 320
# ... снять ...
adb shell wm size reset && adb shell wm density reset
```

## Грабли, на которые уже наступили

**Статус-бар.** Команда demo mode `network` не заменяет иконку, а добавляет
новую — за сессию их накапливается три штуки. Функция `demo` в `demo.sh` делает
`exit` перед `enter`, поэтому не накапливает. Не вызывайте `network` в обход неё.

**Скриншоты в галерее.** `adb shell screencap -p /sdcard/s.png` попадает в
медиа-индекс, и ваш собственный скриншот вылезает в пикере и в галерее
приложения. Снимайте в `/data/local/tmp` — он не сканируется. Так и делает `shoot`.

**`adb exec-out` в Git Bash.** Редирект бинарного вывода портит PNG. Нужен
`screencap` на устройство плюс `adb pull`.

**Пути в Git Bash.** Перед любой командой с `/sdcard` или `/data` ставьте
`export MSYS_NO_PATHCONV=1`, иначе путь превратится в windows-подобный.

**Гранты Photo Picker.** Приложение не имеет разрешений на медиа и читает файлы
только по грантам от пикера. Гранты становятся постоянными лишь после
«Сохранить» в приложении — до этого `persisted=0x0`, и они умирают на первом же
`am force-stop`. Подробности в шапке `seed_db.py`.

**Имена тегов не переводятся.** Они лежат в Room строками, а не в ресурсах.
Смена локали приложения их не трогает — между комплектами гоняйте `seed_db.py`.

**Пикер всегда на языке системы.** `cmd locale set-app-locales` меняет язык
только приложения. Если пикер должен попасть в кадр, придётся менять
системную локаль.

## Вёрстка карточки

Константы в `render_cards.py`:

```
W, H = 1080, 1920      # требование Play: >=1080 по меньшей стороне,
                       # большая сторона не длиннее двух меньших
CAP_TOP = 80           # базовая линия первой строки = CAP_TOP + ascent
CAP_SIZE = 62          # кегль подписи
LEADING = 14           # добавка к высоте строки
MARGIN = 72
```

Строки подписи ставятся **по базовым линиям**, а не по верху чернил. Если
считать от чернил, просвет гуляет: «ё» поднимает верх строки, «р», «у», «д»
опускают низ. Не возвращайте `textbbox`-вёрстку.

`fit=True` подбирает ширину панели так, чтобы кадр поместился целиком и ничего
не срезалось по нижнему краю. Из-за этого ширины панелей в комплекте разные —
это осознанный размен в пользу целых элементов интерфейса.

## Фирменные величины

```
градиент фона   #5B3FA8 -> #2E1B58   (у иконки нижняя точка #3B2470)
акцент-ярлык    #FFB020
подсветка тега  #4CAF50   Material Green 500
подпись         #FFFFFF, пояснение #CBBFEA
```

Зелёный для подсветки взят не из палитры приложения: тамошний `#36CF36`
(`lerp(Gray, чистый зелёный, 0.6)`) на фиолетовом фоне выглядит кислотным, а
синий `#3636CF` почти сливается.

## Требования Play, которые проверяются

| Ассет | Размер | Формат |
|---|---|---|
| Иконка | 512×512 | 32-битный PNG, без прозрачности |
| Feature graphic | 1024×500 | PNG/JPEG, без альфы |
| Скриншоты телефона | 1080×1920 | 2–8 штук, отношение сторон ≤ 2 |

Иконка для витрины — **не** отрисовка холста 108 dp один в один: лаунчер
показывает лишь центральные 72 dp, поэтому для Play берётся кроп безопасной
зоны, иначе рисунок в магазине выглядит мельче, чем на телефоне.
