# search module

## Описание
Модуль, отвечающий за поиск добавленных ранее медиа по тегам.

## Структура
```
tags/
├── src/
│   └── main/
│       └── java/
│           └── com/dgopadakak/tagsgallery/search/
│               ├── screen.kt             # Composable код
│               └── SearchViewModel.kt    # ViewModel, содержащая UiState

```

## Основные компоненты
- SearchViewModel: ViewModel, которая управляет состоянием UI (`UiState`) и взаимодействует с репозиторием из модуля core/local_storage
- UI компоненты

## Функционал
- Отображение списка всех доступных тегов с возможностью сортировки (по имени, дате, цвету) и фильтрации (по цвету).
- Выбор одного или нескольких тегов для поиска.
- Динамическое обновление списка найденных медиа-файлов при изменении набора выбранных тегов.
- Отображение превью найденных медиа-файлов в виде сетки.
- Отображение выбранных тегов в нижней панели (sheet), которая может быть развернута для полноэкранного выбора тегов.
- Отображение подсказки при первом входе на экран.

## Зависимости
- Jetpack Compose для UI
- Hilt для inject'а зависимостей
- Coil для отображения превью медиа
- core/compose для переиспользования общих UI компонентов
- core/local_storage для работы с репозиторием
