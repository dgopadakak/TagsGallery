# tags module

## Описание
Модуль, отвечающий за управление тегами, предоставляет пользователю CRUD функционал.

## Структура
```
tags/
├── src/
│   └── main/
│       └── java/
│           └── com/dgopadakak/tagsgallery/tags/
│               ├── TagsViewModel.kt     # ViewModel, содержащая UiState
│               └── ui/                  # Composable код
```

## Основные компоненты
- TagsViewModel, взаимодействующая с репозиторием из модуля core/local_storage
- UI компоненты

## Функционал
- Создание новых тегов
- Просмотр существующих тегов с возможностью сортировки и фильтрации отображаемого списка
- Редактирование существующих тегов
- Удаление тегов

## Основные зависимости
- Jetpack Compose для UI
- Hilt для inject'а зависимостей
- core/local_storage для работы с репозиторием
- core/compose для переиспользования общих UI компонентов
